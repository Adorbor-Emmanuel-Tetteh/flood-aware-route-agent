\# Synthetic Data Notes



All data in this repository is \*\*synthetic and simulated only\*\*. This project is a simulation, not real navigation software.



\## What Is Included

\- \*\*Synthetic road networks:\*\* Simulated graphs with node coordinates and edge travel costs generated deterministically from a random seed.

\- \*\*Synthetic flood / road closure scenarios:\*\* Simulated closure configurations (e.g., fixed/known-in-advance closures, closures discovered on arrival, and dynamic mid-trip closures) across varying closure rates and random seeds.

\- \*\*Scenario metadata:\*\* Seed values, start and destination nodes, closed edges/nodes, and route availability indicators.



\## Data and Ethics Notice

\- No real-world personal data or human participants are used.

\- No passwords, credentials, or external API keys are stored or required.
