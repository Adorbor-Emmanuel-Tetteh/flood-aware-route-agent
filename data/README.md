# Data datasheet

All data in this repository is synthetic and simulated only. This project is a simulation, not real navigation software.

## Source and how it is created
- Generated by `src/generate_data.py` (fixed seed, so the same seed always gives the same file).
- Road network: a grid of junctions (6 x 6 by default). Each junction is joined to the one on its right and the one below it.
- Each road gets a travel cost chosen at random between 1.0 and 3.0 (2 decimal places).
- A share of the roads (the closure ratio, default 0.2) is picked at random and marked closed with a flood severity between 0.5 and 1.0.
- Start junction is the top-left corner and goal is the bottom-right corner.
- Default seed in the sample file: 42 (`data/sample_network_seed42.json`).

## Allowed use
Classroom project only.

## Quality checks
- Same seed gives the same network (automated test).
- Node and road counts match the grid size (automated test).
- Every road costs at least 1.0, so a grid-distance heuristic never overestimates.

## Known limits
- The maps do not represent real Accra roads or live traffic, so results may not carry over to real conditions.
- The generator does not yet check whether a route still exists after closures are applied.
- Closure type is currently stored on each closed road. The team still has to decide how "which roads are closed" and "when the agent finds out" are kept separate.
